Saves, mods & controls

Default keyboard: Space = Start, X = A, C = B, WASD = movement, Z = target, arrow keys = C buttons. Press Esc for settings and configurable keyboard/gamepad bindings. When save states are enabled, F5 saves, F6 changes slots, and F7 loads. Tab switches alternate assets.

Pair a Bluetooth controller in your device's Bluetooth settings, or connect it by USB. Press a controller button while this tab is focused, then configure it in the in-game controller menu.

Press a button on your paired controller to detect it.

Mods load at startup. Use .o2r mods compatible with this version.

Import a randomizer spoiler JSON, then choose a new randomizer save in file select. Generate new seeds from the in-game randomizer menu.
